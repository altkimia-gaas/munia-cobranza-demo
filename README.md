# MunIA Cobranza — MVP demostrable

**Demo en línea:** https://altkimia-gaas.github.io/munia-cobranza-demo/

Instrumento de conversación para reuniones con municipios chilenos: brecha padrón–SII, reloj de prescripción por cuota (art. 2521/2518 CC), actos vs. avisos, informe de antecedentes con firma fundada, carga y conciliación de archivos reales (procesamiento 100% local en el navegador).

> **Todos los datos son sintéticos** — municipalidad ficticia de Villa Esperanza. Ninguna cifra corresponde a un municipio real. No es un producto en operación.

- App autocontenida en `index.html` (sin backend, sin dependencias; solo Google Fonts).
- Para actualizar la demo: reemplazar `index.html` y push a `main` — GitHub Pages publica solo en ~1 minuto.
